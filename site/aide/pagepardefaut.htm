LES NOMS DES PAGES HTML

les noms des fichiers

Pour composer votre site, vous pouvez donner n'importe quel noms aux pages, il suffit qu'elles ne comportent pas de caractères spéciaux.. accents, espaces..

Ces fichiers doivent avoir pour extensions .htm, .html ..

les fichiers affichés par défaut

Quand un visiteur de votre site tape http://www.citeweb.net/login, notre serveur va chercher ce qu'on appelle la page par défaut pour l'afficher.. voici, dans l'ordre, les fichiers qu'il recherche

index.ctw
index.shtm
index.stm
index.ssi
index.html
index.htm
