LES QUESTIONS LES PLUS FREQUEMENT POSEES

Ici vous trouverez des réponses aux questions que les gens nous posent souvent à tech@citeweb.net .. les réponses seront toujours les mêmes.

"Je voudrais installer mes propres CGI, ou mes scripts en PERL ou ASP est-ce possible ?"

Hé non, ce n'est pas possible. Un CGI est un programme qui est exécuté par le serveur pour produire des pages html, ecrire des fichiers .. cela pose deux problèmes sur les serveurs de CITEWEB.NET:

- performances: l'exécution de multiples CGI non spécifiquement codés pour l'architecture des serveur, ou qui comportent des erreur de programmation (ce qui arrive a tout le monde, on fait non propres CGI ca fait planter de temps en temps les machines) dégradent les performances. Si on veut que CITEWEB.NET garde sa bonne fiabilité actuelle, on ne peut se permettre de laisser cet accès.

- sécurité: un programme en CGI peut accéder à de nombreuses ressources au niveau des serveurs que nous n'avons pas le moyen de limiter sous la plateforme logicielle que l'on utilise (Windows NT server)

L'équipe de CITEWEB.NET s'efforce de développer par contre un ensemble assez important de CGI, d'extensions afin de palier à cette interdiction, il n'y a qu'a consulter l'aide pour voir le nombre important d'extensions qui sont développées à ce jour. Si vous avez besoin d'un CGI, écrivez nous, nous verrons si nous pouvons le développer. Actuellement une extension "livre d'or est en développement"

"Avez vous les extensions FRONTPAGE ?"

On aurait pu les installer mais on ne l'a pas fait. Pour des raisons de performances du serveur tout d'abord (les extensions frontpage ralentissent les serveurs), puis ensuite et surtout parceque nous avons choisi de développer nos propres extensions, compatibles avec tout le monde même l'utilisateur qui n'a qu'un simple éditeur de fichiers textes ou un logiciel html qui n'est pas frontpage.

Les extensions que nous développons sont de plus assez simples à mettre en place, plus performantes que celles proposées par les extensions frontpage.

"Peut-on limiter un accès à un répertoire par mot de passe"

Non, nous avons pour but de publier des sites sur internet, pas de cacher des pages. Pas de limitation par mot de passe donc.. mais si vous le désirez vous pouvez faire une page html dans un sous repertoire de votre compte, qui ne sera linkée de nulle part.. personne ne pourra la trouver .. sauf ceux a qui cette URL "cachée" sera communiquée !

"Applets JAVA qui ne charge pas les images"

C'est sûrement un problème de compatibilité du java avec le standard html 1.0. Pour contourner ce problème, renommez si vous le pouvez les images utlisées par vos applets de la manière suivante :
image.gif -> image.gif_
image.jpg -> image.jpg_
Modifiez la config de vos applets en conséquence.
Site exemple : http://reeeeez.citeweb.net

"L'envoi des fichiers sur le FTP n'est pas très rapide"

Pour des raisons techniques on l'a limité à 2 ko/s par connexion. Si vous utilisez LeechFTP cette limitation ne vous gênera pas car il fait plusieurs connexions simultanées.

"Certains de mes fichiers ont disparus !"

Parfois nous faisons des vérifications anti-virus. Les fichiers infectés sont irrémédiablement effacés. Vérifiez les avant de les envoyer.
De plus, les fichiers de plus de 0.5 Mo (512 Ko) sont automatiquements effacés dès l'envoi sur le FTP (ces fichiers ne respectent pas les règles d'hébergement). Dans ce dernier cas un mail vous est automatiquement envoyé sur votre email login@citeweb.net pour vous le signaler.

"Mon adresse http://citeweb.net/login ne fonctionne pas !"

Qui vous a dit qu'elle était sensée fonctionner ? ;-) A une epoque elle marchait effectivement, mais on n'a jamais dit que ca devait être le cas et que ce n'était pas un bug (ben oui, les bugs peuvent aussi agir dans le bon sens ;). Bref, votre adresse c'est http://www.citeweb.net/login (avec un www hein ;) ou http://login.citeweb.net ou même http://login.ctw.cc ou encore http://www.ctw.cc/login (on va s'arrêter là pour le moment, c'est déja bien =).

"Mon répondeur ne fonctionne pas tout le temps"

Pour éviter que de surcharger les serveurs (pas seulement les notres ;-), le répondeur est réglé pour ne répondre qu'une fois par jour à chaque personne. Ainsi, si quelqu'un vous envoie deux mails dans la même journée, il ne recevra la réponse automatique du répondeur que la première fois.
