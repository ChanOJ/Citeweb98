INSTALLER LE MOTEUR DE RECHERCHE PERSONNEL

Vous voulez un moteur de recherche sur votre site ? Dans quelques minutes cela sera réalité. Une moulinette tourne continuellement pour indexer les sites hébergés par CITEWEB. Vous pouvez mettre sur votre site un moteur qui recherche soit sur tout CITEWEB, soit sur un site seulement.

> appeler le moteur de recherche pour qu'il fasse une recherche sur CITEWEB

Dans votre page html, il suffit d'insérer cette partie de code html:

<form action="http://pom.citeweb.net/cgi/search.htm" method="POST">
<input type="text" size="20" name="SearchString">
</form>

cela fera apparaitre un formulaire de recherche sur votre site:

Il suffira d'appuyer sur entrée pour lancer la recherche.

Si vous voulez, vous pouvez rajouter la ligne suivante avant le </form> pour obtenir un bouton de validation :
<input type="submit" name="ACTION" value="Go">

> recherche sur un site particulier

Vous voulez que le moteur ne recherche que sur un seul site ? Par exemple seulement sur /OJUICE ? Il suffit de rajouter la ligne suivante avant le </form> :
<input type="hidden" name="FORMSCOPE" value="/OJUICE">

Vous l'aurez compris par vous même, il suffit de changer la valeur de FORMSCOPE, mais attention n'oubliez pas le / au début, autrement cela ne marchera pas.

> configuration

Plusieurs paramètres sont à votre disposition pour personaliser la page de résultats. Il s'agit à chaque fois de lignes à rajouter avant le </form>. Vous pouvez n'en mettre que certaines, ou bien les mettre toutes. Les valeurs par défaut sont celles de CITEWEB.

Changer la langue:

Actuellement seul l'anglais et le français sont disponibles. Pour avoir les résultats en français vous n'avez rien a rajouter.
<input type="hidden" name="LANGUAGE" value="English">

Changer l'image de tête:

Pour ceux qui utilisaient l'ancien système, ne vous inquiétez pas il est encore valide, mais nous vous conseillons d'utiliser celui-ci maintenant.
<input type="hidden" name="IMAGE" value="http://ojuice.citeweb.net/pictures/search.gif">

Changer la largeur de page:

La largeur par defaut du tableau où sont affichés les pages correspondant à la recherche est 420 pixels. Pour régler cette valeur à 600 par exemple, ajoutez ligne suivante:
<input type="hidden" name="PageWidth" value="600">

Choisir le cadre de destination dans la page des résultats de la recherche:

Si vous utilisez des frames, vous pouvez choisir dans quelle frame les liens trouvés par le moteur s'ouvriront:
<input type="hidden" name="TargetWindow" value="_blank">
Remplacez _blank par le nom de votre fenêtre, dans cet exemple les liens s'ouvrent dans une nouvelle fenêtre.

Changer les couleurs:

Voici les différentes lignes disponibles
<input type="hidden" name="ColorBg" value="000000">
<input type="hidden" name="ColorText" value="FFFFFF">
<input type="hidden" name="ColorLink" value="FF8040">
<input type="hidden" name="ColorVlink" value="FF8040">
<input type="hidden" name="ColorTableBg" value="004080">

Les 4 premiers paramètres agissent sur le tag BODY. ColorTableBg règle la couleur de la barre qui apparait en fin de page.

> trucs et astuces

Préselectionner le champ de saisie:

Pour que l'utilisateur n'ait pas besoin de cliquer sur le champ de formulaire pour pouvoir écrire dedans, il suffit de rajouter les lignes suivantes juste après le </form>.
<SCRIPT language="JavaScript"><!--
document.moteur.SearchString.focus();
//--></SCRIPT>

Il faut aussi modifier la première ligne du formulaire ainsi:
<form action="http://pom.citeweb.net/cgi/search.htm" method="POST" name="moteur">

Empêcher le moteur d'indexer un fichier au format html:

Il suffit de rajouter la ligne suivante entre les deux balises <HEAD> et </HEAD>:
<meta name="robots" content="noindex">
