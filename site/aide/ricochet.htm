RICOCHET, l'espioneur des liens

Ricochet est une extension serveur qui vous permet de surveiller les liens externes de votre site (par exemple votre série de liens vers vos sites préférés).
Il vous indique lorsqu'un lien ne fonctionne plus, par exemple si le serveur sur lequel vous demandez une page est en panne, ou bien si une page n'existe plus, ou encore si une page a été déplacée sur un autre serveur ou a une adresse différente.

Vous avez deux choix:
Avec l'option 1 Ricochet vous informe lorsque le lien que vous avez demandé n'existe plus, en vous envoyant une email
Avec l'option 2 Ricochet vous informe lorsque le lien que vous avez demandé n'existe plus, ou que le serveur sur lequel vous avez demandé la page est injoignable (momentanément en panne ?) ou encore si la page que vous appelé a été déplacée, pour vous aider à optimiser ce lien (pour qu'il soit plus rapide à la consultation).

Pour appeler le script c'est très simple, il vous suffit de rajouter "http://www.citeweb.net/ricochet?1;" ou bien "http://www.citeweb.net/ricochet?2;" (sans les guillemets) deavnt votre lien dans les propriétés de celui-ci.

Ce qui donne par exemple :
http://www.citeweb.net/ricochet?2;http://www.citeweb.net
au lieu de :
http://www.citeweb.net

Dans ce cas je receverais un mail lorsqu'un visiteur de mon site à cliqué sur mon lien vers CITEWEB qui ne fonctionne pas (ou bien la façon de l'optimiser).

Exemple d'un lien surveillé par Ricochet :
Lien sur CITEWEB, surveillé par Ricochet

Je receverais un mail lorsque le serveur ne repondra plus ou si c'est une erreur 404.

Résumé des messages reçus par Ricochet:

LIEN LENT
Ce lien n'est pas direct, c'est à dire que la page que vous demandez utilise peut-être par exemple un service de renvoi d'url, ou bien que la page a été deplacée sur un autre serveur. Utilisez les infos fournies par Ricochet pour optimiser vos liens (accéder directement a la page voulue sans passer par des étapes inutiles).

LIEN INDISPONIBLE
Le serveur sur lequel se trouve la page que vous demandez est momentanément indisponible. C'est normalement passager, mais cela peut aussi être définitif.

LIEN MORT
Le serveur sur lequel se trouve la page que vous avez demandé n'existe plus ou bien la page que vous demandez a été supprimée. Vous pouvez donc retirer ce lien de votre site.
