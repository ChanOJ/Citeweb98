FAIRE DES INCLUDES

> Utilisation des includes

Sur toutes les pages web de votre site vous proposez le même texte (une barre de menu par exemple) et vous désirez changer ce texte sans changer toutes les pages de votre site ?

Un include sert à afficher le contenu d'un fichier texte, ou d'une page HTML dans une autre page web. Ceci pour pouvoir ainsi, par exemple changer une ligne de texte dans votre page d'index sans avoir à changer toute la page.

Dans notre exemple, je vais insérer un commentaire qui se trouve dans un fichier texte à l'intérieur de ma page.
Pour appeler les includes, le tag à insérer est $$INC:inc/include.txt$$
inc: répertoire dans votre site où se trouve votre fichier include (ne pas mettre de / devant le répertoire)
include.txt: le nom de votre include

Voici le contenu de mon fichier include.txt:
<font face="Verdana, Arial, Helvetica, sans-serif" size="1">Aujourd'hui il pleut </font>

Voici la source de la page où je veux insérer mon include:

<html>
<head>
<title>Le temps en direct !</title>
<meta http-equiv="Content-Type" content="text/html; charset=iso-8859-1">
</head>
<body bgcolor="#FFFFFF">
<p><font face="Verdana, Arial, Helvetica, sans-serif" size="2"><b>Suivre le temps
en direct !</b></font></p>
<p><font face="Verdana, Arial, Helvetica, sans-serif" size="2">Quel temps fait
il aujourd'hui ?</font></p>
<p>$$INC:include.txt$$</p>
</body>
</html>

Voici la source de la page qui sera envoyée à vos visiteurs

<html>
<head>
<title>Le temps en direct !</title>
<meta http-equiv="Content-Type" content="text/html; charset=iso-8859-1">
</head>
<body bgcolor="#FFFFFF">
<p><font face="Verdana, Arial, Helvetica, sans-serif" size="2"><b>Suivre le temps
en direct !</b></font></p>
<p><font face="Verdana, Arial, Helvetica, sans-serif" size="2">Quel temps fait
il aujourd'hui ?</font></p>
<p><font face="Verdana, Arial, Helvetica, sans-serif" size="1">Aujourd'hui il pleut </font></p>
</body>
</html>

Vous pouvez remplacer le fichier texte par un fichier contenant un lien vers une image par exemple...
