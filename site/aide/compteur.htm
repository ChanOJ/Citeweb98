CONFIGURER SON COMPTEUR

> installer le compteur sur sa page web

Le compteur est très simple a installer.. dans n'importe quelle page html au lieu de taper maison ou poireau, vous tapez $$CPT$$ et vous aurez un compteur !

Le $$CPT$$ doit absolument paraître tel quel dans votre fichier, sinon notre serveur ne saura pas reconnaitre votre compteur une fois votre page installée.

> configuration du compteur

allez dans la section membres de CITEWEB et configurez l'aspect de votre compteur.. texte, images du serveur ou vos images personnelles

> vos images personelles pour le compteur ?

si vous le désirez, notre compteur affiche vos propres chiffres, pour cela, creez et envoyez dans le répertoire principal de votre compte les gifs correspondants (un pour chaque chiffre de 0 à 9 et ayant pour nom 0.gif, 1.gif..)
