Aide sur NickServ

Le NickServ est un service qui gere les pseudonymes. Grace a lui vous pouvez enregistrer, proteger votre pseudonyme.

Pour envoyer une commande tapez (a partir d'un client IRC, car de l'interface web ceci ne marche pas)

  /msg NickServ <commande>

Commandes

Drop

Identify

Info

Ghost

Recover

Access

Set-PASSWD

Help

Cette commande demande au NickServ de vous envoyer via des notices (type de message privé) la liste des fonctions existantes. Malheuresement elle est en anglais donc a vos dictionnaires. Cette commande est tres pratique en cas d'oubli d'une fonction.

Register

Cette commande est la premiere commande que vous devez envoyer. Elle permet de proteger son pseudonyme, grace a elle vous aurez access a toutes les autres commandes

Syntaxe : /msg NickServ Register <mot de passe>

N.B : Elle enregistre votre pseudonyme courant, donc pensez a utiliser le bon pseudonyme au moment ou vous l'envoyez. Le mot de passe doit faire plus de 5 lettres et doit etre en un seul mot (exemple : Papa est invalide (car trop court) et ma maman fait des gateaux est aussi invalide (car en plusieurs mots) )

Drop (vous devez etre authetifié)

Cette commande est l'inverse de la commande Register elle enleve votre pseudonyme de la base de donné. Vous pouvez l'utilisé si vous voulez vous arreter de faire de l'IRC.

Syntaxe : /msg NickServ Drop

Indentify

Cette commande est la commande que vous utiliserez (a mon avis le plus souvent). Elle permet de vous identifier.

Syntaxe : /msg NickServ Identify [Pseudo] <mot de passe>

N.B : Le mot de passe corespond a celui que vous avez utilisé quand vous avez envoyé la commande Register

Conseil : Quasiment tout les clients IRC permetent d'envoyer des commandes quand vous vous connectez au serveur. La plupart du temps ce champ se nomme Perform sous mIRC cliquez sur File ensuite Option et ensuite recherchez l'onglet (si vous etes sur une version anterieure a la version 5.5). Dans ce champs tapez /msg NickServ Identify <pseudo> <passe> affin de vous authentifier à la connection.

Info

Cette commande demande au NickServ de vous envoyer les information sur un psudonyme (Utilisée ou non, Date de la derniere authentification, hotes valides)

Syntaxe : /msg NickServ Info <pseudo>

Ghost

Cette commande sert a expulser une personne qui utilise votre pseudonyme

Synatxe : /msg NickServ Ghost <pseudo> <mot de passe>

Recover

Cette commande est un peu complexe a expliquer, mais ... tres utile des que l'on sait bien s'en servir. Elle coupe la connection de la personne qui utilise votre pseudo (comme la fonction ghost) mais en plus crée un utilisateur virtuel avec votre pseudo afin que personne ne puisse le prendre.

Syntaxe : /msg NickServ Recover <pseudo> <mot de passe>

Conseil : Si vous n'etes pas tres bon en IRC utiliséz la commande SET KILL expliquée plus loin.

Release

Cette commande est l'inverse de la commande Recover elle enleve l'utilisateur virtuel utilisant votre pseudo.

Syntaxe : /msg NickServ Release <pseudo> <mot de passe>

Access (Vous devez etre identifié)

Vous permet de gerer la liste des hotes autorisée (lieux de connection) pour l'utilisation de votre pseudo. Elle possede plusieurs sous-fonction

List

Affiche la liste des hotes autorisée

Syntaxe : /msg NickServ Access List

Add

Ajoute une hote autorisée

Syntaxe : /msg NickServ Access Add <masque>

Del

Enleve un masque autorisé

Syntaxe : /msg NickServ Access Del <masque>

Set (vous devez etre authentifié)

Cette fonction sert a modifier la gestion de votre pseudo. Elle possede plusieurs sous fonction

Kill

Cette fonction active (desactive) l'autokill. Si il est activé vous avez 40 secondes pour vous authentifié ou changer de pseudo. Sinon le serveur coupe votre connection.

Syntaxe : /msg NickServ Set Kill {ON|OFF}

N.B Vous devez mettre ON ou bien OFF mais pas les deux

URL

Cette commande change l'adresse de votre page web.

Syntaxe : /msg NickServ Set URL [Adresse]

Si vous ne mettez pas d'adresse il considere que vous n'en posedez pas

PASSWD

Change votre mot de passe

Syntaxe : /msg NickServ Set PASSWD <mot de passe>

 

Voila vous connaisez toutes les fonction de gestion d'un pseudonyme si malgres ceci vous avez des problemes, verifiéz (commande INFO) que le pseudonyme n'est pas deja utilisée, ou ecrivez a irc@citeweb.net un des administrateurs vous repondra.
