Aide sur Gaia

Gaia est le service qui vous permet de créer votre propre canal, avec vos listes d'operateurs, etc.. Ce service n'est pas géré avec des Eggdrop (pour ceux qui conaisent) et est tres stables (les bots font partie du serveur citeworld, qui n'accepte aucune conection).

Pour envoyer une commande tapez (a partir d'un client IRC, car de l'interface web ceci ne marche pas). Attention toutes les commandes ne marchent que si vous etes dans le NickServ

  /msg NickServ <commande>

Help

Cette commande demande a Gaia de vous envoyer via des notices (type de message privé) la liste des fonctions existantes. Malheuresement elle est en anglais donc a vos dictionnaires. Cette commande est tres pratique en cas d'oubli d'une fonction.

Register

Cette commande est la premiere commande que vous devez envoyer. Elle permet d'enregistrer, grace a elle vous aurez access a toutes les autres commandes

Syntaxe : /msg Gaia Register #Canal <mot de passe> <description>

N.B : Le mot de passe, deviend le mot de passe Administrateur. La seule personne qui doit conaitre ce mot de passe ... c'est VOUS.

Drop (vous devez etre authetifié)

Cette commande est l'inverse de la commande Register elle enleve votre canal de la base de donné. Vous pouvez l'utilisé si votre canal devint peu (voire pas) fréquenté..

Syntaxe : /msg Gaia Drop <mot de passe>

Info

Cette commande vous permet de savoir si un canal est enregistré, et vous envoie la description et l'adresse de sa page web.

Syntaxe : /msg Gaia Info #canal

Identify

Cette commande vous permet de conferer a l'utilisateur qui l'envoie les commandes de créateur du cannal.

Syntaxe : /msg Gaia Identify #canal <mot de passe>

N.B : N'utilisé cette commande que sur le createur réel de la salle sinon vous vous exposé a de gros risques (entre autre de perdre votre place de createur)

Invite (ne marche que si vous etes au moins AOP)

Cette commande vous invite sur un canal en mode +i que si vous etes au moins AOP

Syntaxe : /msg Invite #chanal

Unban (a partir de AOP)

Vous permet d'enlever tous les bans du canal

Syntaxe : /msg Gaia Unban #canal

MKick (a partir de AOP)

Cette commande éffectue un 'Mass Kick' soit impose un kick a toutes les personnes d'un canal

Syntaxe : /msg Gaia MKick #canal

N.B : Cette commande ne sert (la plupart du temps) que lorseque l'on veut empecher un TO (Take Over explications sur http://hiersay.citeweb.net)

Mode (a partir de AOP)

Cette commande change les modes du canal

Syntaxe : /msg Gaia #canal <modes>

UnMode (a partir de AOP)

Cette commande enleve tous les modes d'un canal. Elle est tres peu utilisée.

Syntaxe : /msg Gaia unmode #canal

AVoice (a partir de AOP)

Cette commande posséde plusieurs sous commandes. Elle vous peremet de gere la liste des AutoVoice de votre canal

List

Liste la liste des AutoVoice

Syntaxe : /msg Gaia AVoice #canal LIST

Add

Ajoute un utilisateur a la liste des Auto Voice

Syntaxe : /msg Gaia AVoice #canal Add <pseudo>

Del

Enleve un utilisateur de la liste des Auto Voice

Syntaxe : /msg Gaia AVoice #canal Del <pseudo>

AOP (a partir de SOP)

Cette commande posséde plusieurs sous commandes. Elle vous peremet de gere la liste des Auto operateurs de votre canal

List

Liste la liste des Auto Operateurs

Syntaxe : /msg Gaia AOP #canal LIST

Add

Ajoute un utilisateur a la liste des Auto Operateurs

Syntaxe : /msg Gaia AOP #canal Add <pseudo>

Del

Enleve un utilisateur de la liste des Auto Operateurs

Syntaxe : /msg Gaia AOP #canal Del <pseudo>

SOP (a partir de Cofounder)

Cette commande posséde plusieurs sous commandes. Elle vous peremet de gere la liste des Super operateurs de votre canal

List

Liste la liste des super operateurs

Syntaxe : /msg Gaia SOP #canal LIST

Add

Ajoute un utilisateur a la liste des Super Operateurs

Syntaxe : /msg Gaia SOP #canal Add <pseudo>

Del

Enleve un utilisateur de la liste des Super Operateurs

Syntaxe : /msg Gaia SOP #canal Del <pseudo>

COFOUNDER (a partir de fondateur)

Cette commande posséde plusieurs sous commandes. Elle vous peremet de gere la liste des Co-fondateurs de votre canal

List

Liste la liste des Co-fondateurs

Syntaxe : /msg Gaia COFOUNDER #canal LIST

Add

Ajoute un utilisateur a la liste des Co-fondateurs

Syntaxe : /msg Gaia COFOUNDER #canal Add <pseudo>

Del

Enleve un utilisateur de la liste des Co-fondateurs

Syntaxe : /msg Gaia COFOUNDER #canal Del <pseudo>

AKick (a partir de AOP)

Cette commande posséde plusieurs sous commandes. Elle vous peremet de gere la liste des Auto Kick de votre canal. Cette liste empeche le proprietaire d'un nick de rentrer, et ne depend pas de bans

List

Liste la liste des Auto Kick

Syntaxe : /msg Gaia AKICK #canal LIST

Add

Ajoute un utilisateur a la liste des Auto Kick

Syntaxe : /msg Gaia AKICK #canal Add <pseudo>

Del

Enleve un utilisateur de la liste des Auto Kick

Syntaxe : /msg Gaia AKICK #canal Del <pseudo>

SET (a partir de Fondateur)

Cette commande possede plusieurs sous commandes

Description

Change la desciption du canal

Syntaxe : /msg Gaia Set #canal DESCRIPTION <description>

URL

Change l'adresse associé au canal

Syntaxe : /msg Gaia Set #canal URL [URL]

N.B : Si vous ometez le parametre alors ocune page n'est associé au canal

Founder

Cette commande vous permet d'enlever conferer a vous mêmes le pouvori e fondateur.

Syntaxe : /msg Gaia Set #canal FOUNDER {ON|OFF}

N.B : L'ennui c que je n'ai pas compris a quoi sert le parametre ON, car pour executer cette commande vous devez etre fondateur.

Protect

Met le canal en mode +nt-iklmsp en continu, ce qui empeche un operateur de changer les modes du canal. Cette commande sera surement utilisé sur #Citeweb mais je vous conseille vivement de le laisser OFF ce qui permet aux operateurs de mieux gerer un canal.

Syntaxe : /msg Gaia Set #canal PROTECT {ON|OFF}

InviteOnly

Cette commande sert a mettre un canal en mode +i en continu. Ceci peut servir a créer un canal tres fermé (je ne vois pas l'utilité).

Syntaxe : /msg Gaia Set #canal INVITEONLY {ON|OFF}

Secret

Cette commande met votre canal en mode +s (on ne le voit donc pas dans les listes des cannaux)

Syntaxe : /msg Gaia Set #canal SECRET {ON|OFF}

MODERATE

Cette commande passe le canal en mode +m. Je ne vois pas non plus l'utilitée de cette fonction, car le +m en continu detruit (a court termes) un canal.

Syntaxe : /msg Gaia Set #canal MODERATE {ON|OFF}

Restrict

Cette commande authorise seulement les Auto Voice ou au dela a rejoindre un canal. Je ne vois pas non plus son interet.

Syntaxe : /msg Gaia Set #canal RESTRICT {ON|OFF}

PASSWD

Cette commande change le mot de passe administrateur du canal.

Syntaxe : /msg Gaia Set #canal PASSWD <mot de passe>

 

Voila vous connaisez toutes les fonction de gestion d'un canal si malgres ceci vous avez des problemes, verifiéz (commande INFO) que le canal n'est pas deja utilisée, ou ecrivez a irc@citeweb.net un des administrateurs vous repondra.
