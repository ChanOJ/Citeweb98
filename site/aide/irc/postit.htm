Aide sur PostIt

Post it est un MemoServ. Il vous permet d'envoyer une note a une personne enregistré dans NickServ même si elle n'est pas presente sur IRC, elle la vera en se conectant.

Commandes

List

Cette commande liste tous vos messages en attentes

Syntaxe : /msg PostIt List

Send

Cette commande envoye une note a un utilisateur

Syntaxe : /msg PostIt Send <pseudo> <message>

Read

Cette commande permet de lire le message spécifié

Syntaxe : /msg PostIt Read <numero>

Del

Cette commande detruit le message spécifié

Syntaxe : /msg PostIt del <numero>

Purge

Cette commande detruit tous vos messages

Syntaxe : /msg PostIt Purge

Recall

Cette commande detruit le dernier message que vous avez envoyé a un utilisateur

Syntaxe : /msg PostIt Recall <pseudo>

Forward

Cette commande fait suivre toutes vos notes a pseudonyme spécifié. Il vous faut préciser le mot de passe du pseudo spécifié

Syntaxe : /msg PostIt Forward <pseudo> <mot de passe>

IgnoreAll

Cette commande demande a Postit d'ignorer tous les memos arrivant.

Syntaxe : /msg PostIt IgnoreAll {ON|OFF}

 

Voila vous connaisez toutes les fonction de gestion des messages si malgres ceci vous avez des problemes ecrivez a irc@???? un des administrateurs vous repondra.
