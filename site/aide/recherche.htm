INTERROGER LE MOTEUR DE RECHERCHE

Les possibilités de recherche sur CITEWEB sont extrêmement évoluées. Voici une liste non exhaustive des opérateurs acceptés dans la zone de recherche. (dans les exemple qui suivent, cliquez sur la zone de saisie puis appuyez sur entrée pour tester l'exemple)

> recherche de base

Une chaine saisie telle quelle sera recherchée de façon exacte:
cherchera très exactement la phrase.

> le jocker

Très utile, par exemple, pour chercher un mot indifféremment au singulier ou au pluriel:
va trouver casser, castagnettes, casse-cou, ...

> opérateurs booléens

Pour rechercher Exemple Resultat
Les deux termes dans la même page access and basic
—ou—
access & basic		 Les pages contenant les deux mots access et basic
Un terme ou l'autre dans la même page cgi or isapi
—ou—
cgi | isapi		 Les pages contenant le mot cgi et celles contenant le mot isapi
Le premier terme mais pas le second access and not basic
—ou—
access & ! basic		 Les pages contenant le mot access mais pas le mot basic
Les pages n'ayant pas une propriété donnée not @size = 100
—ou—
! @size = 100		 Les pages qui ne font pas 100 octets
Les deux termes dans la même page, à condition qu'ils soient proches l'un de l'autre excel near project
—ou—
excel ~ project		 Les pages contenant le mot excel près du mot project

> recherche d'une phrase contenant des mots réservés

Il suffit d'entourer la chaine à rechercher avec des guillemets:

> les propriétés

Les propriétés doivent êtres précédées d'un arrobas (@) si elles ont utilisées avec un opérateur, sinon elles doivent être précédées d'un dièse (#)
Propriétés Descriptions
Filename Nom du fichier
Size Taille du fichier
Write Date de modification du fichier
DocTitle Titre du document
DocSubject Sujet du document
DocAuthor Auteur du document
DocKeywords Mots clefs indiqués dans le document

Exemples:
Pour chercher Exemple Resultat
Une propriété mise en relation avec une valeur @size < 100
@size <= 100
@size = 100
@size != 100
@size >= 100
@size > 100 		Devinez ! ;-)
Une valeur exacte @DocAuthor = Bill Barnes Les fichiers dont l'auteur est Bill Barnes
Une valeur à prefixe #DocAuthor George* Les fichiers dont le nom de l'auteur commence par George
Certains types de fichiers #filename *.|(exe|,dll|,sys|) Les fichiers portant les extensions .exe, .dll, ou .sys
Les fichiers modifiés après une date donnée @write > 96/2/14 10:00:00 Bon, ca va, c'est compréhensible quand même !
Les fichiers modifiés après une date relative @write > -1d2h Les fichiers modifies il y a moins de 26 heures
