ENVOYER DES EMAILS AVEC UN FORMULAIRE

Cette extension serveur vous permet de vous faire envoyer sur votre email CITEWEB (ou tout autre(s) email(s) de votre choix) tout formulaire mis sur votre site web.

> appeler ce CGI:

tout simplement par le tag form de l'html, comme l'exemple ci dessous. ATTENTION ! Ce cgi ne fonctionne que si il est appelé à partir d'une page hébergée par CITEWEB.

<form action="http://v19.citeweb.net/cgi/formmail.cgi"
method="POST">
</form>

ou si vous utilisez frontpage, allez dans propriétés du formulaire, sélectionnez CGI script puis configuration et dans action mettez
http://v19.citeweb.net/cgi/formmail.cgi

> les champs de configuration:

Ce cgi a été fait pour être simple, mais puissant.

Lorsque le CGI est exécuté, il rajoute au formulaire l'adresse ip de la personne qui envoie le formulaire, son domaine, le navigateur et le système d'exploitation qu'il utilise. Cette fonction vous permet de savoir si une même personne a envoyé plusieurs formulaires à la suite.

adresse ip du client : ????
nom du client : ????
user agent : Mozilla/4.0 (compatible; MSIE 4.0; Windows 95)

Entre les balises <form ...> et </form> vous pouvez inclure des champs cachés pour passer des parametres au cgi. Ces champs n'apparaitront pas dans l'email que vous recevrez :

FORM_SUJET   le sujet du mail envoyé :
<input type="hidden" name="FORM_SUJET" value="mail d'essai du formmail">
     
FORM_OK   le nom de la page html à afficher une fois le formulaire envoyé, avec une référence absolue :
<input type="hidden" name="FORM_OK" value="http://www.citeweb.net/login/page.htm">
     
FORM_DEST   email d'un destinataire (ou de plusieurs, séparés par des virgules) du formulaire. seuls les 5 premiers emails seront pris en compte :
<input type="hidden" name="FORM_DEST" value="login@citeweb.net,webmaster2@citeweb.net">
     
FORM_OBLIG   permet de spécifier les noms des champs que l'utilisateur ne doit pas laisser vides :
<input type="hidden" name="FORM_OBLIG" value="nom,prenom,age">
     
FORM_NOMBRE   permet de spécifier les noms des champs qui ne peuvent contenir que des nombres (et optionnellement de spécifier dans quel intervalle doivent se situer chacun de ces nombres) :
<input type="hidden" name="FORM_NOMBRE" value="age(6:100),telephone,annee(1910:2000)">
     
FORM_ERREUR   le nom de la page html (référence absolue) à afficher si le formulaire rempli par l'utilisateur ne satisfait pas aux conditions que vous avez spécifié :
<input type="hidden" name="FORM_ERREUR" value="http://www.citeweb.net/erreur.htm">

 

Entre les balises <form ...> et </form> vous pouvez inclure des champs texte (tous optionnels) pour améliorer l'email que vous recevrez. Ces champs apparaitront dans l'email :

FORM_NOM   le nom (de famille ou complet) de l'utilisateur :
<input type="texte" name="FORM_NOM" value="entrez votre nom ici">
     
FORM_PRENOM   le prénom de l'utilisateur :
<input type="texte" name="FORM_PRENOM" value="entrez votre prénom ici">
     
FORM_EMAIL   l'email de l'utilisateur (cet email apparaitra dans le champ "from:" de l'email que vous recevrez, ce qui fait que vous pourrez directement répondre à l'utilisateur, à condition qu'il ai bien entré son email bien sûr) :
<input type="texte" name="FORM_EMAIL" value="entrez_votre@ email.ici">

> explications :

<form method="POST" action="http://v19.citeweb.net/cgi/formmail.cgi">

indique l'emplacement de notre CGI

<input type="hidden" name="FORM_SUJET" value="mail d'essai du formmail">

ce message apparaitra comme sujet de l'email que vous recevrez.

<input type="hidden" name="FORM_OK" value="http://www.citeweb.net/login/ok.htm">

le visiteur verra cette page si l'email a été envoyé.

<input type="hidden" name="FORM_ERREUR" value="http://www.citeweb.net/login/erreur.htm">

le visiteur verra cette page s'il a fait une erreur.

<input type="hidden" name="FORM_OBLIG" value="age,commentaire">

spécifie que les champs age et commentaire ne doivent pas êtres laissés vides.

<input type="hidden" name="FORM_NOMBRE" value="age(6:100),telephone">

spécifie que le champ age doit contenir soir rien, soit un nombre entre 6 et 100 inclus. spécifie aussi que le champ telephone doit contenir soit rien, soit un nombre.

<input type="hidden" name="FORM_DEST" value="moi@monprovider.com">
<input type="hidden" name="FORM_DEST" value="moncopain@son.email">

spécifie les destinataires de l'email (vous et un secon webmaster par exemple). si ces champs ne sont pas présent, l'email arrivera sur votre email citeweb.

<input type="text" size="20" name="FORM_PRENOM">

si le champ email (voir plus bas) est rempli, le prenom apparaitra dans la zone indiquant l'envoyeur de l'email, en plus d'apparaitre dans le corps du message.

<input type="text" size="20" name="FORM_NOM">

si le champ email (voir plus bas) est rempli, le nom apparaitra dans la zone indiquant l'envoyeur de l'email, en plus d'apparaitre dans le corps du message.

<input type="text" size="20" name="age">

apparaitra dans le corps de l'email.

<input type="text" size="20" name="FORM_EMAIL">

sera placé comme envoyeur de l'email, et apparaitra dans la corps du message.

<input type="text" size="20" name="telephone">
<textarea name="commentaire"></textarea>
<input type="submit" value="Envoyer">
</form>

fin du formulaire, standard.
