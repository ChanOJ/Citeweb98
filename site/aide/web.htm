CREER SON SITE WEB

Un site web est composé de pages web, (les .htm) qui sont écrites en langage html. Vous pouvez ainsi créer un site web avec un simple éditeur de texte comme notepad mais cela suppose de connaitre l'HTML..

Mais, il existe des éditeurs HTML qui sont des programmes qui vous permettent de faire des pages web pour votre site sans connaitre aucune commande HTML .. en éditant simplement votre page web à la manière d'un traitement de texte.

Vous pouvez télécharger des éditeurs HTML sur internet:

Dreamweaver de Macromedia
client ftp intégré, rapide, superbe, dernières normes HTML supportées (nouveaux navigateurs internet explorer 4.0 et netscape 4.0, DHTML)

Frontpage 98 de Microsoft(c)
très répandu mais lent ..

Les logiciels de navigation comme internet explorer 4.0 et netscape 4.0 ont aussi intégrés des éditeurs html, par exemple frontpad qui est une version allégée de frontpage

Vous pouvez aussi transformer les documents que vous créez avec WORD, EXCEL, POWERPOINT ou PUBLISHER de Microsoft en page html .. utilisez les assitants internet qui sont en téléchargement gratuit sur le site de Microsoft france
